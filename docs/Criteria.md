# PART V — FINAL MVP ACCEPTANCE CHECKLIST

## 24. Release Criteria

The MVP is considered complete when the following conditions are met.

### Authentication
- [ ] Students can sign in.
- [ ] Students can sign out.
- [ ] User identity is associated with database records.

### Map and Discovery
- [ ] Rose Hill map works.
- [ ] Lincoln Center map works.
- [ ] Students can switch campuses.
- [ ] Activity markers render correctly.
- [ ] Selecting a marker opens activity details.
- [ ] Activity list view works.

### Activity Management
- [ ] Students can create activities.
- [ ] Invalid activity submissions are rejected.
- [ ] Activities appear in the discovery feed.
- [ ] Activities have valid locations and timestamps.
- [ ] Hosts can cancel their activities.

### Participation
- [ ] Students can join activities.
- [ ] Students can leave activities.
- [ ] Duplicate participation is prevented.
- [ ] Participant capacity is enforced.
- [ ] Participant counts update in real time.

### Quality
- [ ] Mobile layout works.
- [ ] Loading states are implemented.
- [ ] Error states are implemented.
- [ ] Firebase rules are configured.
- [ ] Core workflows are tested.
- [ ] The application is deployed and accessible.
